# 課程 Prompts

## 先讀 Widget，不修改

> 請先檢查 `CampScheduleWidgetExtension`，不要修改程式。找出 Widget、Provider、TimelineEntry、View 與 Preview；說明資料如何從 Provider 傳到畫面；確認目前 Target 能否 Build；列出下一步預計修改的檔案。

## 實作基本 Widget

> 把 Widget 改成 Summer Camp 日程 Widget。依活動開始時間建立 Timeline Entries；顯示目前與下一個活動；只支援 `systemMedium`；加入三個時間點的 Preview；不要修改 App Target 與專案 Signing。完成後 Build Widget Target。

## 建立 Branch

> 從最新的 `main` 建立 `feature/＿＿＿＿` Branch，只完成「＿＿＿＿」這一項修改。開始前先同步 `main`；列出預計修改的檔案；不改其他組員負責的範圍；完成後 Build，再整理 Diff。

## Commit

> 只 Commit「＿＿＿＿」這一項功能。先檢查 `git status` 與 Diff；排除其他人或使用者既有的變更；提出清楚的 Commit message；Commit 後再次確認狀態。

## Pull Request

> Push 目前 Branch，建立合併到 `main` 的 Pull Request。摘要改了什麼、列出測試方式與尚未完成的項目；不要自行 Merge。
