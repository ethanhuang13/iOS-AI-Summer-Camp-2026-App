# 01｜Apple 原生框架研究

目標：看到 App 功能需求時，先確認 Apple 是否已提供原生解法，再決定要不要自己做或使用第三方服務。

## 練習

從自己的 App 選一項尚未實作的功能，貼給 Codex：

> 我想在 iOS App 實作「＿＿＿＿」功能。請優先研究 Apple 是否提供原生 Framework 或服務，只參考 Apple 官方文件，並附上來源連結。
>
> 請整理：
> 1. 建議使用的 Framework 或 API
> 2. 可以完成什麼、不能完成什麼
> 3. 最低系統版本與裝置限制
> 4. 是否需要 Capability、Entitlement 或使用者權限
> 5. 是否有費用、配額或使用限制
> 6. 隱私權與 App Review 注意事項
> 7. 最小可行的實作步驟
>
> 先不要寫程式。如果 Apple 沒有合適的原生方案，也請明確說明。

## 分享

- 想做什麼
- 找到什麼原生解法
- 有什麼限制
- Apple 官方文件在哪裡

本專案的例子：「不打開 App，就能看到接下來的活動」→ WidgetKit。
